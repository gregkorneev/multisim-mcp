# Установка Multisim MCP в Windows

Скопируйте всю папку проекта в постоянное место на Windows 10/11, распакуйте
архив и запустите `install-windows.bat` двойным кликом. Нужен интернет.
Для автоматической установки Python и Node.js нужен WinGet из Microsoft App
Installer. Установка Node.js может запросить права администратора.

Батник устанавливает Python 3.13 **32-bit**, если его нет в стандартном месте,
Node.js LTS, изолированное окружение MCP с `pywin32` и остальными зависимостями,
а также кодек `electronics-workbench-decoder@0.2.0`. Затем он готовит настройки
Codex и создаёт набор шаблонов из локальных примеров Multisim. Перед созданием
шаблонов сохраните открытые проекты; установщик дождётся нажатия Enter.
В конце выполняется диагностика с проверкой COM и лицензии.

**NI Multisim 14+ и его лицензию установите отдельно.** Установщик использует
примеры из установленного Multisim; поставка без этих примеров не сможет создать
набор шаблонов. Codex также должен быть установлен отдельно.

Файлы установки находятся в `%LOCALAPPDATA%\MultisimMcp`:

- `venv32` — Python-окружение сервера;
- `npm` — кодек `.ms14`;
- `component-pack` — локальные шаблоны;
- `codex-multisim.toml` — готовый блок настроек;
- `logs` — журналы установки.

Скопируйте содержимое `codex-multisim.toml` в
`%USERPROFILE%\.codex\config.toml` (или в `config.toml` внутри своего `CODEX_HOME`).
Если раздел `mcp_servers.multisim` уже есть, замените именно этот раздел и его
таблицу `env`, избегая дубликатов. Затем перезапустите Codex и попросите:
«Проверь Multisim MCP через runtime_status». Установщик генерирует отдельный
файл настроек; существующая конфигурация Codex редактируется вручную.

Для установки зависимостей до установки Multisim откройте CMD в папке проекта:

```bat
install-windows.bat -SkipTemplates
```

Если Python 32-bit (версии 3.11+) или примеры Multisim установлены в другом месте:

```bat
install-windows.bat -Python32 "D:\Python32\python.exe" -SamplesRoot "D:\NI\Circuit Design Suite 14.3\samples"
```

Повторный запуск переиспользует окружение и готовый набор шаблонов. Ошибки
останавливают установку с ненулевым кодом; подробности сохраняются в журнале.
После ошибки исправьте указанную причину и запустите батник снова. Если набор
шаблонов создан лишь частично, переместите его в резервную папку перед повтором;
установщик не перезаписывает существующие шаблоны.

Не перемещайте папку проекта после установки: MCP устанавливается из неё в
editable-режиме. Для нового расположения запустите батник из новой папки и
обновите настройки Codex.

Проверка синтаксиса PowerShell и обработки ошибок без установки:

```bat
install-windows.bat -SelfCheck
```

Для запуска без финальной паузы задайте `MULTISIM_MCP_NO_PAUSE=1`.
